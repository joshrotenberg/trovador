# trovador

Local Claude Code and Codex sessions as one MCP server and CLI: search the archive, start,
continue, and consult sessions across backends.

The Rust successor to [spike](https://github.com/joshrotenberg/spike). Work in progress; see
[#1](https://github.com/joshrotenberg/trovador/issues/1) for the v0.1 scope.
